# 📖 Overview

YATRA is a next-generation digital tourism platform developed to enhance tourism experiences in **Jharkhand** through intelligent trip planning, destination discovery, cultural storytelling, and environmental awareness.

The platform bridges tourists, local communities, and government authorities while promoting responsible tourism practices.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/shivamkumardsai/YATRA-Tourism-Platform.git
```

```
cd YATRA-Tourism-Platform
```

---

# Frontend Setup

```bash
cd design-system

npm install

npm run dev
```

Runs at

```
http://localhost:5173
```

---

# Backend Setup

```bash
cd backend

pip install -r requirements.txt

uvicorn main:app --reload
```

Runs at

```
http://127.0.0.1:8000
```
